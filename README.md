# 冬马和纱桌宠

这是一个 Windows 桌宠原型。重点不是堆功能，而是维持冬马和纱的克制、孤高、怕受伤又不善表达的气质。

## 启动

双击 `启动桌宠.bat`。需要 Windows 与 Python 3（含 Tkinter，标准 Windows Python 安装通常自带）。

程序带有单实例保护；桌宠已经运行时再次点击启动脚本，不会再创建第二个桌宠。

## 操作

- 拖动：移动桌宠。
- 左键：让她简短回应。
- 右键：打开菜单，可以切换姿势、开始/结束学习、使用番茄钟、静音或退出。
- `Esc`：退出。

她在闲置时通常保持沉默，约一至两分钟才可能说一句；选择“暂时安静”后不会主动发言。

气泡会按照句末标点自动分句；包含多句话时，每句话单独占一行。

开始学习后，每学习约 25 分钟她会简短评价一次；这时点击她会被视为摸鱼。每约 45 分钟还会提醒起身活动。

番茄钟提供 25 分钟专注和 5 分钟短休息，可暂停、继续或提前结束。计时期间左上方会显示冷蓝色倒计时；专注计时会自动进入学习监督状态，完成后自动退出。

## 人设依据与设计取舍

- 动画官网将她描述为峰城大学附属学园三年 E 班学生、春希的邻座，常居眠、逃课，以孤独而带刺的态度与同学保持距离。
- 官方访谈提到她的尖锐是为了避免再次受伤，实际上怕寂寞，情绪失控时又会显露孩子气的一面。
- 因此本桌宠不使用高频卖萌、热情欢迎、黏人撒娇等反应；对白以短句、嘴硬、保持距离和偶尔泄露关心为主。
- 形象采用约 3.2 头身的 Q 版比例，保留黑蓝长直发、克制的蓝灰眼睛、黑色校服外套、白衬衫、蓝色领带与蓝格裙。素材根据用户提供的原作设定图生成，没有直接打包官方图片。程序中显示高度约 250 像素，避免遮挡过多桌面区域。

## 文件

- `kazusa_pet.py`：桌宠程序，只使用 Python 标准库。
- `assets/kazusa-q.png`：透明背景 Q 版原始立绘，保持原样。
- `assets/kazusa-q-display.png`：由原始立绘进行 Lanczos 高质量缩放得到的显示缓存，程序按 1:1 像素绘制，避免 Tkinter 近邻缩放产生锯齿。
- `assets/kazusa-q-pose2.png`：相同画风和比例的低位侧坐姿势原始立绘。
- `assets/kazusa-q-pose2-display.png`：第二姿势的高质量显示缓存。
- `assets/kazusa.png`：上一版立绘，保留作备份。
- `启动桌宠.bat`：无控制台窗口启动器。
